# METTMAXXX SMS ASSISTENT

**METTMAXXX SMS ASSISTENT** ist eine kostenlose Android-App zum manuellen Versenden einzelner SMS.

Telefonnummer und Nachricht werden direkt in der App eingegeben. Eine SMS wird ausschließlich dann versendet, wenn der Benutzer selbst auf das große METTMAXXX-Logo drückt.

Es gibt keinen automatischen Nachrichtenversand.

## Datenschutz

Die App sammelt, speichert oder übermittelt keine persönlichen Daten an den Entwickler oder an externe Server.

Die App besitzt keine Internet-Berechtigung und enthält keine Werbung, keine Analyse-Dienste und keine kostenpflichtigen Funktionen.

Telefonnummern und eingegebene SMS-Texte werden ausschließlich für die vom Benutzer ausgelöste SMS verwendet.

## Benötigte Berechtigung

Die App benötigt die Android-Berechtigung:

**SMS senden (`SEND_SMS`)**

Diese Berechtigung ist notwendig, damit die App eine vom Benutzer eingegebene SMS über das Mobiltelefon versenden kann.

Die App benötigt keinen Zugriff auf Kontakte, Standort, Kamera, Mikrofon oder Internet.

## Installation

Da die App als APK außerhalb des Google Play Stores angeboten wird, kann Android beim Installieren zusätzliche Sicherheitsabfragen anzeigen.

Je nach Android-Version muss zunächst die Installation aus dieser Quelle zugelassen werden.

Auf neueren Android-Geräten kann die SMS-Berechtigung zusätzlich als eingeschränkte Berechtigung behandelt werden.

Falls „SMS zulassen“ ausgegraut ist:

**Einstellungen → Apps → METTMAXXX SMS ASSISTENT → Drei-Punkte-Menü → Eingeschränkte Einstellungen zulassen**

Anschließend:

**Berechtigungen → SMS → Zulassen**

Android zeigt diese zusätzliche Sicherheitsabfrage bei bestimmten außerhalb des Play Stores installierten Apps zum Schutz des Benutzers an.

## Kosten

Die App selbst ist **kostenlos** und enthält keine In-App-Käufe, Abonnements oder Werbung.

**Hinweis:** Beim Versenden einer SMS können abhängig vom Mobilfunkvertrag des Benutzers die normalen SMS-Gebühren des Mobilfunkanbieters entstehen.

Bei Tarifen mit SMS-Flatrate entstehen in der Regel keine zusätzlichen SMS-Kosten.

## Verwendung

Die App ist für den manuellen Versand einzelner SMS vorgesehen.

**Ein Tippen auf das METTMAXXX-Logo = eine SMS.**

Der Benutzer entscheidet selbst über Empfänger, Inhalt und jeden einzelnen Versand.
